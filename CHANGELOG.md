## [0.1.0] - 2026-11-27

### Adicionado

- Estrutura inicial do projeto Node.js (`package.json`, `.gitignore`);
- `README.md` com descrição do projeto, Reforma Tributária do Consumo
  (EC 132/2023, LC 214/2025, LC 227/2026) e cronograma de transição;
- `CONVENCIONAL.md` — convenções de Conventional Commits e Conventional Branch;
- `CONTRIBUTING.md` — guia de contribuição com boas práticas de GitHub Issues;
- Issue forms: `bug_report.yml`, `feature_request.yml`, `question.yml`,
  `suggestion.yml` e `config.yml`;
- Template de Pull Request;
- `GOVERNANCE.md` — papéis, versionamento SemVer e processo decisório;
- `LICENSE` — licença MIT;
- `CODE_OF_CONDUCT.md` — Código de Conduta do Contributor Covenant;
- `SECURITY.md` — política de segurança e canal privado de reporte;
- `CHANGELOG.md` — este arquivo.

### Alterado

- Nota de origem: port Node.js do projeto Java em
  [ReceitaFederal/calculadora-rtc-regime-regular](https://github.com/ReceitaFederal/calculadora-rtc-regime-regular).
